# Security Policy

## Supported Versions

Security fixes are considered for the latest `1.0.x` release. Older versions
may not receive security fixes.

## Reporting A Vulnerability

Use [GitHub Security Advisories](https://github.com/awesome-sas/saspytest/security/advisories/new)
to report a vulnerability privately. Include the affected version, reproduction
steps, impact, and any relevant security context.

Do not include credentials, SAS configuration files, proprietary code, or other
secrets in a public issue. If Security Advisories are unavailable, open a public
issue containing only a request for maintainer contact and no sensitive details.

Please allow maintainers reasonable time to investigate before publicizing a
confirmed vulnerability.
